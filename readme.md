## Sobre o Projeto

Este projeto é uma tela de login temática para um estúdio de fotografia. O foco principal foi criar uma experiência visual imersiva que remeta à arte da fotografia, utilizando contrastes e uma interface limpa.

Foi desenvolvido como um desafio de interface (UI Design) para praticar a construção de layouts elegantes e navegação entre estados de login e cadastro.

### Funcionalidades

- [x] Login com e-mail e senha pré-definidos
- [x] Navegação fluida entre telas
- [x] Layout responsivo focado em estética visual

## About

This project is a themed login screen for a photography studio. The main focus was to create an immersive visual experience that reflects the art of photography, using contrast and a clean interface.

It was developed as a technical UI challenge to practice building elegant layouts and navigation between login and signup states.

### Features

- [x] Login with predefined email and password
- [x] Fluid navigation between screens
- [x] Responsive layout focused on visual aesthetics
